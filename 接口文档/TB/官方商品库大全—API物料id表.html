【官方教程】官方商品库大全—API物料id表

官方推荐商品库大全

（物料精选API获取material_id汇总）

 

为了繁荣淘宝客生态，淘宝联盟官方致力于为广大淘宝客提供优质商品库做推广。

本帖针对有开发能力的淘宝客，通过API获取对应的商品库，实现接口转链，数据实时更新，使用更便捷更高效。

 

本功能涉及到的API：通过入参字段物料id(即material_id字段)获取商品库。物料id会在本帖中不定期更新！

--淘宝客-推广者-物料精选升级版：taobao.tbk.dg.material.recommend(适用于自己推广的媒体)【API详细字段点此查看】

--淘宝客-推广者-物料搜索升级版 ：taobao.tbk.dg.material.optional.upgrade(适用于工具服务商)【API详细字段点此查看】

备注：若未与联盟确认过为工具服务商(仅极少淘客是)，都请直接使用推广者API【官方教程】淘宝客API/SDK介绍总帖

 

API出参的商品相关信息字段包含：

-商品基本信息（宝贝ID、主图、类目、标题、销量等）

-券相关信息（券总量、券剩余量、券开始时间、券使用门槛等）

-佣金信息 （佣金比例等）

-推广链接（单品淘宝客链接、二合一链接等）

3、收藏夹

选品库是指淘宝联盟在https://pub.alimama.com/后台——>我要推广——>商品推广 中，所提供给淘宝客批量管理和获取所需推广物料的功能，您可创建不同的收藏夹，比满足对不同类型商品筛选和管理的需要。进入“收藏夹”后，即可看到您所创建的所有收藏夹及对应商品，可修改并增减商品。

想要通过API获取选收藏夹的商品，需要通过API获取，一共两步：

①获取收藏夹列表：入参固定的物料id 31519，分页从1开始如下图，出参字段为：favorites_info，获得具体的收藏夹id及收藏夹名称

②获取每个收藏夹的商品列表：入参固定的物料id 31539（注意不是上面的31519哦！！！），分页从1开始，以及所获得的收藏夹id（字段为：favorites_id），就可以后的对应收藏夹内的所有商品列表。【升级版物料接口仅返回收藏夹商品ID，商品更多信息可根据商品ID前往其他物料接口调用】
